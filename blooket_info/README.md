# Blooket: информатика (InfoTany)

100 наборов × 15 вопросов, отдельно на казахском (`kz/NN.csv`) и русском (`ru/NN.csv`). Названия — в `index.md`.

Импорт в Blooket: Create a Set → Import Questions from a Spreadsheet → загрузить `NN.csv`
(Blooket подхватывает шаблон: строка 1 — заголовок, строка 2 — названия столбцов, далее вопросы). Название набора в Blooket
введите вручную, например «Информатика №01. Ақпарат ұғымы және қасиеттері».

Исходники: `src/part*.txt` (формат строки описан в `convert.ps1`). Пересборка CSV: `powershell -File convert.ps1`
(проверяет 15 вопросов в наборе, длину вопроса ≤ 300 и ответа ≤ 75 символов, дубли ответов).

Тексты сгенерированы ИИ по курсу InfoTany; верный ответ в KZ и RU стоит на одной и той же позиции. Нужна проверка учителем.
