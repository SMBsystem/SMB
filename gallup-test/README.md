# Тест сильных сторон (прототип в формате Gallup)

Статический сайт, без сборки: открыть `index.html` (на GitHub Pages работает как есть).

| Файл | Что внутри |
|---|---|
| `data.js` | 4 области, 34 таланта, по 3 утверждения на талант, описания и советы |
| `data.kz.js` | казахский перевод талантов и областей (по `id` из `data.js`) |
| `data.en.js` | английский перевод талантов и областей |
| `data.career.js` | профессии, «зоны внимания» по талантам, тексты областей и карьерный путь (RU / KZ / EN) |
| `i18n.js` | тексты интерфейса и раздела анализа RU / KZ / EN |
| `engine.js` | построение набора пар, подсчёт баллов, проверка достоверности |
| `app.js` | интерфейс: таймер, сохранение прогресса, экран результата |
| `style.css` | оформление (светлая и тёмная тема) |

## Как устроен тест

- 51 пара утверждений из разных талантов, шкала из 5 ступеней (точно А … точно Б).
- Схема сбалансирована: пары получены из кругового турнира, поэтому каждый талант встречается ровно 3 раза и ни одна пара талантов не повторяется.
- Стороны А/Б и порядок пар перемешиваются; пары с общим талантом не идут подряд.
- 20 секунд на пару, возврата назад нет, дедлайн хранится в браузере (перезагрузка страницы времени не добавляет).
- Балл таланта = сумма предпочтений по его парам (от −6 до +6). Равенство разрешается по числу «точно», затем по числу побед.
- 6 контрольных зеркальных повторов проверяют согласованность ответов.
- Достоверность: пропуски, слишком быстрые ответы, перекос в одну сторону экрана, преобладание «затрудняюсь», согласованность.

## Язык

Переключатель ҚАЗ / РУС / ENG в правом верхнем углу работает на всех экранах, в том числе посреди теста (таймер при этом не сбрасывается). Выбор запоминается; по умолчанию язык берётся из настроек браузера. Новые утверждения нужно добавлять во всех трёх файлах: `data.js`, `data.kz.js`, `data.en.js`.

## Анализ и карьерные рекомендации

В конце результата выводится раздел «Анализ вашего профиля»:

- портрет по ведущей и второй областям и по топ-5 талантов;
- «на что обратить внимание» — риски перекормленных сильных сторон из топ-5;
- баланс областей: самая слабая область и как её подтянуть;
- 8 профессий: у каждого таланта 5 профессий, топ-5 талантов дают по 2 балла, места 6–10 по 1;
- карьерный путь из трёх этапов для ведущей области.

Тексты и списки профессий лежат в `data.career.js`. Если результат помечен как ненадёжный, анализ получает пометку «предварительный».

## Ограничения

Это учебный прототип, не официальный CliftonStrengths®/Gallup®. В нём 51 пара вместо 177, поэтому
надёжность ниже, чем у оригинала; чтобы повысить её, добавьте в `data.js` по 1–2 утверждения на талант
и дополните список `ROUNDS` в `engine.js` (по 17 пар на каждый тур, максимум 33 тура).
