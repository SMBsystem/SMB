# Тест сильных сторон (прототип в формате Gallup)

Статический сайт, без сборки: открыть `index.html` (на GitHub Pages работает как есть).

| Файл | Что внутри |
|---|---|
| `data.js` | 4 области, 34 качества (официальные названия, как в отчётах Gallup), по 6 утверждений на качество, описания и советы |
| `data.kz.js` | казахский перевод качеств и областей (по `id` из `data.js`) |
| `data.en.js` | английский перевод качеств и областей |
| `data.career.js` | профессии, «зоны внимания» по качествам, тексты областей и карьерный путь (RU / KZ / EN) |
| `i18n.js` | тексты интерфейса и раздела анализа RU / KZ / EN |
| `axes.js` | 10 осей сравнения и «естественные» пары качеств (общая ось) |
| `adaptive.js` | оценка силы качеств с погрешностью (порядковая логит-модель) и выбор пар для уточнения |
| `engine.js` | построение основной части, подбор уточняющих пар, подсчёт, проверка достоверности |
| `app.js` | интерфейс: таймер, сохранение прогресса, два этапа, экран результата |
| `style.css` | оформление (светлая и тёмная тема) |

## Как устроен тест

**Этап 1 — основная часть (51 пара + 6 контрольных).**
- Пары утверждений из разных качеств, шкала из 5 ступеней (точно А … точно Б).
- Пары выбираются только «естественные»: у двух качеств есть общая ось сравнения (см. ниже). Схема сбалансирована: три непересекающихся «паросочетания» из естественных пар, поэтому каждое качество встречается ровно 3 раза и ни одна пара качеств не повторяется. Используются утверждения №1–3 каждого качества.
- Стороны А/Б и порядок пар перемешиваются; пары с общим качеством не идут подряд.
- 6 контрольных зеркальных повторов проверяют согласованность ответов.

**Этап 2 — уточнение (40 адаптивных пар).**
- После основной части тест оценивает силу каждого качества вместе с погрешностью и ищет качества, чьи места ещё неясны: в первую очередь на границах «топ-5» и «топ-10».
- Для следующей пары берутся два таких качества, которые ещё не сравнивались друг с другом и набрали близко (максимальная неопределённость порядка). Пары без общей оси получают вес 0,5, поэтому выбираются реже. После каждого ответа оценка пересчитывается.
- Утверждения берутся наименее показанные у качества: сначала неиспользованные №4–6, затем повторно показанные (с другим соперником).

**Общие правила.** 20 секунд на пару, возврата назад нет, дедлайн хранится в браузере (перезагрузка времени не добавляет), прогресс сохраняется.

**Подсчёт.** Сила качества — байесовская оценка (нормальный априор, порядковая логит-модель ответа) по всем ответам. Она учитывает, с кем и как часто качество сравнивали, поэтому корректна и при разном числе сравнений. Рейтинг строится по этой оценке; в списке показаны «баллы» — оценка в условных единицах.

**Достоверность:** пропуски, слишком быстрые ответы, перекос в одну сторону экрана, преобладание «затрудняюсь», согласованность повторов и стабильность профиля (оценки по чётным и нечётным ответам, корреляция с поправкой Спирмена — Брауна).

## Оси сравнения

Утверждения разных качеств не всегда естественно сравнивать («жить по распорядку» против «собирать работу в одно целое»). Поэтому качества размечены по 10 осям с двумя полюсами: люди (широкий круг — уединение), темп (действовать сразу — сначала обдумать), порядок (структура — гибкость), опора (факты — интуиция), время (прошлое — будущее), мотив (победа — согласие), правила (единые — индивидуальные), смысл и результат, ум и действие, руководство (вести — поддерживать). Пара «естественна», если у качеств есть общая ось; пары с разных полюсов контрастны сильнее всего (как «знакомства» против «работы в одиночку»). Всего 206 из 561 возможных пар естественны, 121 из них контрастны. Разметка — экспертная оценка автора, правится в `axes.js`.

Строго ограничиться естественными парами нельзя: точность падает (около 3,4 из 5 попаданий в топ-5). Мягкое предпочтение сохраняет точность и поднимает долю естественных пар: основная часть на 100% из естественных, в целом по тесту около 83% (раньше 36%).

## Проверка на смоделированных респондентах

Движок прогнан на тысячах искусственных респондентов с известным «истинным» профилем. Шум ответов σ = 1 (умеренный):

| Схема | Пар | Точных попаданий в топ-5 |
|---|---|---|
| только основная часть, 3 утверждения на качество | 51 | 2,7 из 5 |
| фиксированный набор, 6 утверждений на качество | 102 | 3,3 из 5 |
| фиксированный набор, 8 утверждений на качество | 136 | 3,4 из 5 |
| 51 основная + 34 фиксированных | 85 | 3,5 из 5 |
| **51 основная (естественные пары) + 40 адаптивных (рабочая версия)** | **91** | **3,9 из 5** |

Адаптивная схема точнее фиксированной даже при меньшем числе пар. При низком шуме (σ = 0,7) 4,1 из 5, при высоком (σ = 1,5) 3,3 из 5 (фиксированные 102 пары: 3,1). В рабочей версии 4–5 из найденной пятёрки входят в «настоящую» десятку, поэтому интерфейс советует смотреть на топ-10 как на группу.

Пороги пометок достоверности подобраны на смоделированных данных: почти все случайные ответы получают пометку (около половины — «ненадёжно»), а у респондентов с умеренным шумом «ненадёжно» бывает примерно в 1% случаев.

## Язык

Переключатель ҚАЗ / РУС / ENG в правом верхнем углу работает на всех экранах, в том числе посреди теста (таймер при этом не сбрасывается). Выбор запоминается; по умолчанию язык берётся из настроек браузера. Новые утверждения нужно добавлять во всех трёх файлах: `data.js`, `data.kz.js`, `data.en.js`.

## Анализ и карьерные рекомендации

В конце результата выводится раздел «Анализ вашего профиля»:

- портрет по ведущей и второй областям и по топ-5 качеств;
- «на что обратить внимание» — риски перекормленных сильных сторон из топ-5;
- баланс областей: самая слабая область и как её подтянуть;
- 8 профессий: у каждого качества 5 профессий, топ-5 дают по 2 балла, места 6–10 по 1;
- карьерный путь из трёх этапов для ведущей области.

Тексты и списки профессий лежат в `data.career.js`. Если результат помечен как ненадёжный, анализ получает пометку «предварительный».

## Ограничения

Это учебный прототип, не официальный CliftonStrengths®/Gallup®. Утверждения написаны самостоятельно и не проходили психометрическую валидацию, нормативной базы нет; в оригинале около 200 пар. Названия и области качеств соответствуют отчётам Gallup (русские — по официальному отчёту), казахские названия — перевод. Чтобы повысить надёжность, добавьте во все три файла `data*.js` ещё по 2–3 утверждения на качество (тогда уточнение реже повторяет тексты), а затем соберите ответы реальных людей и проверьте утверждения по ним.
