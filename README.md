# Образовательный Мульти-Портал «GeoTany & GeoNISH»

Проект организован по модульной структуре: главный портал в корне и независимые каталоги для каждого учебного курса.

---

## 📁 Структура каталогов и файлов

```text
/
├── index.html                           # Главный портал (выбор курсов: Геотану, ГеоНИШ и др.)
├── README.md                            # Описание структуры и руководство
├── google_sheets_registration_script.js # Скрипт синхронизации с Google Таблицами
│
├── geotanu/                             # [КУРС 1] «GeoTany» (География ҰБТ / ЕНТ)
│   ├── index.html                       # Главный дашборд курса GeoTany
│   │
│   ├── nomenklatura/                    # Модуль: Географическая номенклатура (ГеоКвест)
│   │   ├── index.html                   # Маршрутизатор номенклатуры
│   │   ├── world_geography_game.html    # Интерактивная карта (русская версия)
│   │   └── world_geography_game_kz.html # Интерактивная карта (казахская версия)
│   │
│   ├── lessons/                         # Модуль: Чтение и разбор (20 уроков на каз. и рус. яз.)
│   │   ├── lesson_01_kz.html ... lesson_20_kz.html
│   │   └── lesson_01_ru.html ... lesson_20_ru.html
│   │
│   ├── maps/                            # Модуль: Тематические карты (QGIS / GEE)
│   │   ├── index.html                   # Каталог тематических карт
│   │   └── map_01.html ... map_50.html
│   │
│   ├── topics/                          # Модуль: Теоретические конспекты и Blooket
│   │   └── topic_01.html ... topic_23.html (и доп.)

    └── index.html                       # Главный дашборд курса ГеоНИШ (14 научных блоков, 42 урока)
```

---

## 🚀 Навигация и запуск

1. **Главная страница (`/index.html`)**:
   - Единая точка входа.
   - Позволяет перейти к любому курсу по кнопке или с помощью промокода (`GeoTanu19_57` или `GeoNISH19_57`).

2. **Курс GeoTany (`/geotanu/index.html`)**:
   - Автономный раздел со всеми модулями: темы конспектов, уроки чтения, номенклатура, карты и тесты.
   - На всех страницах модулей предусмотрена кнопка возврата `←` на главный экран курса `geotanu/index.html`.
   - В шапке курса предусмотрена кнопка возврата в общий портал `../index.html`.

3. **Номенклатура (`/geotanu/nomenklatura/`)**:
   - Игра «ГеоКвест» на русском и казахском языках.
   - Включает адаптивное сопоставление ответов (устойчивость к опечаткам в 1–2 буквы, распознавание полных официальных названий и аббревиатур).

4. **Курс ГеоНИШ (`/geonish/index.html`)**:
   - Специализированный раздел естествознания и географии для подготовки к конкурсу НИШ/БИЛ.
