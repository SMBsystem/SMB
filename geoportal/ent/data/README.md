# Курс «ЕНТ-тренажёр»: как добавить тест

Тесты по направлениям (полный ЕНТ: 120 вопросов, 140 баллов, 4 часа) лежат в `data/tests/<id>.js`,
а список всех тестов — в `data/index.js`, массив `REG`.

## 1. Строка в `REG`

```js
E.REG = [
  { id: 'bio-geo-ru-01', dir: 'bio-geo', lang: 'ru', n: 1 },   // русское отделение, вариант 1
  { id: 'bio-geo-kz-01', dir: 'bio-geo', lang: 'kz', n: 1 }    // казахское отделение, вариант 1
];
```

`dir` — id направления из `E.DIRS` (там же пары предметов), `lang` — язык теста (`ru` или `kz`), `n` — номер варианта.
Страница направления показывает, сколько тестов уже есть из `E.TARGET` (50).

## 2. Файл теста `data/tests/<id>.js`

```js
window.ENT.tests['bio-geo-ru-01'] = {
  html: true,                 // в тексте есть разметка: формулы MathML, <img>, <sub>, <sup>, таблицы
  minutes: 240,
  contexts: {                 // материал к группе заданий (текст, карта, схема)
    c1: { title: 'Карта', html: 'Используя карту, выполните задания 11–15.<img src="data/img/bio-geo-ru-01_c1.png" alt="">' }
  },
  sections: [                 // порядок: история, чтение, мат. грамотность, два профильных предмета
    { id: 'hist', questions: [ /* 20 */ ] },
    { id: 'read', questions: [ /* 10 */ ] },
    { id: 'mlit', questions: [ /* 10 */ ] },
    { id: 'bio',  questions: [ /* 40 */ ] },
    { id: 'geo',  questions: [ /* 40 */ ] }
  ]
};
```

`id` раздела — ключ из `E.SUBJ`. Картинки кладите в `data/img/` и пишите путь от папки `ent/`.

## 3. Формат вопроса (как в `geotanu/tests/data/README.md`)

```js
{ type: 'single', q: 'Текст вопроса', options: ['A', 'B', 'C', 'D'], answer: 2, explanation: '…' }       // 1 балл
{ type: 'single', ctx: 'c1', q: '…', options: [...], answer: 0 }                                          // вопрос к материалу c1
{ type: 'single', q: '…', img: 'data/img/bio-geo-ru-01_q15.png', options: [...], answer: 1 }              // с рисунком
{ type: 'multi',  q: '…', options: [6 вариантов A–F], answer: [0, 3] }                                    // 2 балла: всё верно — 2, одна ошибка — 1
{ type: 'match',  q: '…', left: ['1) …', '2) …'], options: ['A) …', 'B) …', 'C) …', 'D) …'], answer: [2, 0] } // по 1 баллу за пару
```

`answer` — индекс (A = 0). В `match` `answer[i]` — индекс варианта для строки `left[i]`.

В ЕНТ на каждый профильный предмет: 1–25 один ответ, 26–30 по материалу, 31–35 соответствие, 36–40 несколько ответов (50 баллов).
Если нужен отдельный тест на одном языке, `lang` в `REG` достаточно: поля `q`, `options` и т. д. показываются как есть.

## Старые тесты

Раздел «Отдельные тесты по предметам» подхватывает готовые варианты GeoTany (`geotanu/tests/data/`, список берётся
из `GEOTANY_TEST_READY`) и «Основы права» (`pravo/data/t01–t04.js`) напрямую, копировать их не нужно.
