# Курс «ЕНТ-тренажёр»: как устроены тесты и как добавить новые

Полный вариант ЕНТ по направлению: 120 вопросов, 140 баллов, 4 часа. Состав: История Казахстана (20) + Грамотность чтения (10) +
Математическая грамотность (10) + два профильных предмета по 40 вопросов (по 50 баллов).

## Наборы (sets)

Один **набор** = один месяц/формат/язык (например, «Сентябрь · оффлайн, русское отделение»). Внутри набора лежат **блоки**
предметов: `hist`, `read`, `mlit` и профильные (`bio`, `geo`, `chem`, `phys`, `math`, `info`, `eng`, `whist`, `law`).
Вариант по направлению собирается из блоков автоматически: история + чтение + мат. грамотность + два предмета направления
(направления перечислены в `data/index.js`, `E.DIRS`). Поэтому один набор даёт сразу все 11 направлений.

Файлы:

| Файл | Что внутри |
|---|---|
| `data/index.js` | предметы `E.SUBJ`, направления `E.DIRS`, список наборов `E.SETS`; список тестов `E.REG` строится сам |
| `data/sets/<id>.js` | блоки набора с вопросами и ключами (`window.ENT.sets['<id>']`) |
| `data/img/<id>/` | картинки набора (карты, схемы, формулы-картинки) |

Сейчас в курсе: `aug1-ru`, `aug1-kz` (Август · набор 1), `aug2-ru`, `aug2-kz` (Август · набор 2; ключи составлены автором сайта без официальных — вопросы с пометкой требуют проверки) и `sep-off-ru`, `sep-off-kz` (Сентябрь · оффлайн).

## Как добавить набор

1. Положите `data/sets/<id>.js` и папку `data/img/<id>/`.
2. Допишите строку в `E.SETS` (`data/index.js`):

```js
{ id: 'sep-off-ru', lang: 'ru', order: 70, label: { ru: 'Сентябрь · оффлайн', kz: 'Қыркүйек · оффлайн' }, dirs: ALL }
```

`order` задаёт порядок по времени (по нему считается номер варианта у направления: самый ранний набор — «Вариант 1»),
`dirs` — какие направления есть в наборе.

## Формат файла набора

```js
window.ENT.sets['sep-off-ru'] = {
  lang: 'ru', html: true,          // html: true — в текстах есть разметка (формулы-картинки, таблицы, <sub>, <sup>)
  blocks: {
    hist: { contexts: { 'hist-c1': { html: '…' } }, questions: [ /* 20 */ ] },
    read: { …10… }, mlit: { …10… },
    bio:  { …40… }, geo: { …40… }    // и остальные профильные предметы набора
  }
};
```

Вопрос:

```js
{ type: 'single', q: '…', options: ['…','…','…','…'], answer: 2 }                      // 1 балл, answer — индекс (A = 0)
{ type: 'single', ctx: 'hist-c1', … }                                                   // вопрос к материалу из contexts
{ type: 'match',  q: '…', left: ['…','…'], options: [4 варианта], answer: [3, 0] }      // по 1 баллу за пару, answer[i] — вариант для left[i]
{ type: 'multi',  q: '…', options: [6 вариантов A–F], answer: [1, 3] }                  // 2 балла: всё верно — 2, одна ошибка — 1
```

Дополнительные поля вопроса:

* `conf: 1 | 2` — ответ в ключе помечен «*» (1) или «**» (2). При `conf: 2` ученик видит предупреждение «требует проверки преподавателем».
* `skip: true` — в ключе нет верного ответа; вопрос не входит в баллы (максимум уменьшается).
* `img` — отдельная картинка к вопросу (путь от папки `ent/`).

Картинки в тексте — обычные `<img src="data/img/<id>/<имя>">`; маленькие (формулы) идут в строку (`class="fi"`), большие — отдельным блоком (`class="fb"`).

## Старые тесты

Раздел «Отдельные тесты по предметам» подхватывает готовые варианты GeoTany (`geotanu/tests/data/`, список берётся
из `GEOTANY_TEST_READY`) и «Основы права» (`pravo/data/t01–t04.js`) напрямую, копировать их не нужно.

## Откуда взяты тесты

Наборы собраны из Word-файлов преподавателя (формулы и рисунки сохранены, служебные «Примечания по содержанию теста» не переносятся).
Ключи — из приложенных файлов с ответами. Ссылки на исходные документы на сайт не выкладываются.
