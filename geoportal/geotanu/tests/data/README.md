# Тесты ҰБТ (раздел «Тесты» на странице курса)

Каждый вариант — отдельный файл `test_NN.js`, собранный по оригиналам:

| Что | Откуда |
|---|---|
| Казахский текст | скан «N нұсқа.pdf» (текст «N нұсқа» в Google Docs — только черновик распознавания) |
| Русский текст и картинки | «Тест N перевод» |
| Правильные ответы | официальный «Жауаптар» (жауап парағы 1–5); «Разбор_Тест N перевод» — только для объяснений, в нём бывают ошибки |
| Картинки | `../img/tNN_qMM.jpg` (общая), `tNN_qMM_kz.jpg` / `_ru.jpg` — если подписи на разных языках |

Ссылки на оригиналы (Google Drive) на сайт не выкладываются.

После добавления или правки варианта запустите `build_index.ps1` — он обновит `index.js`
(число вопросов, баллы, время). Вариант, которого нет в `index.js`, открывается из старого банка в `geotanu.html`.

## Формат

```js
window.GEOTANY_TESTS = window.GEOTANY_TESTS || {};
window.GEOTANY_TESTS[1] = {
  id: 1,
  timeMinutes: 45,
  contexts: {                     // текст к заданиям «контекст негізінде» (обычно 26–30)
    c1: { title_kz, title_ru, kz, ru }   // kz/ru — HTML, абзацы через <br><br>
  },
  questions: [
    { id: 1, type: 'single',      // один ответ — 1 балл
      q: '…', q_ru: '…',
      options: ['…', …], options_ru: ['…', …],
      answer: 3,                  // индекс верного варианта (A = 0)
      explanation: '…', explanation_ru: '…' },

    { id: 26, type: 'single', ctx: 'c1', … },        // вопрос к тексту c1 (текст показывается перед первым таким вопросом)

    { id: 15, type: 'single', img: 'tests/img/t01_q15.jpg', … },   // картинка к вопросу
    { id: 37, type: 'multi', img: 'tests/img/t01_q37_kz.jpg', img_ru: 'tests/img/t01_q37_ru.jpg', … },

    { id: 31, type: 'match',      // соответствие A/B → 1–4: по 1 баллу за каждую верную пару
      left: ['палеозой', 'мезозой'], left_ru: […],
      options: ['неоген', 'триас', 'девон', 'төрттік'], options_ru: […],
      answer: [2, 1] },           // A → 3, B → 2 (индексы в options)

    { id: 36, type: 'multi',      // один или несколько ответов — 2 балла: всё верно 2, одна ошибка 1
      options: [6–8 вариантов], answer: [5] }
  ]
};
```

Структура отличается по вариантам: в 1–10 — 40 вопросов (1–25 один ответ, 26–30 по тексту, 31–35 соответствие,
36–40 один или несколько ответов; 50 баллов), в 11–22 по листу ответов — 35 вопросов (26–35 с несколькими ответами),
в последних вариантах — до 8 вариантов ответа (A–H). Для каждого варианта структуру берите из оригинала и листа ответов.
