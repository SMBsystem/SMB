## 🔐 Как устроен вход

* **Ученик** вводит на главной странице код курса, имя и почту.
  Коды курсов в коде сайта **не хранятся открытым текстом** — только их SHA-256 хеш.
  Коды выдаёт преподаватель; в README и на страницах их нет.
* **Администратор** входит на главной странице: `Ctrl + Shift + A` → пароль.
  Пароль проверяет сервер (Google Apps Script) — на сайте его нет.
  После входа админ-режим работает и на страницах курсов в той же вкладке.
* Регистрации попадают в Google Таблицу преподавателя, на почту приходит уведомление.

> Важно: сайт статический, поэтому страницы курсов технически доступны
> по прямой ссылке тому, кто знает адрес и умеет пользоваться инструментами
> разработчика. Код курса — это «дверь» для учеников, а не банковский сейф.
> Если нужна настоящая защита материалов, их придётся отдавать через сервер
> (например, Google Apps Script или любой хостинг с авторизацией).

## ⚙️ Сервер регистраций (один раз, ~5 минут)

1. Создайте Google Таблицу, например «GeoTany — ученики».
2. В ней: **Расширения → Apps Script**. Удалите всё в `Code.gs`,
   вставьте содержимое `google_sheets_registration_script.js`, сохраните.
3. **Настройки проекта** (шестерёнка слева) → **Свойства скрипта** → добавить:
   `ADMIN_PASSWORD` = новый длинный пароль.
4. **Развернуть → Новое развёртывание → Веб-приложение**
   (Выполнять как: **Я**, Доступ: **Все**). Разрешите доступ.
5. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`
   и вставьте его в `index.html` в строку `const API_URL = '';`.
6. Откройте сайт, зарегистрируйтесь тестово — строка появится в листе
   «Регистрации», а письмо придёт на почту.

Пока `API_URL` пустой, сайт работает как раньше: ученики входят по коду,
но регистрации сохраняются только в их браузере, а админ-панель недоступна.

После изменения кода скрипта: **Развернуть → Управление развёртываниями →
✏️ → Версия: новая → Развернуть** (адрес не меняется).

## 🔑 Смена кодов курсов

Старые коды были опубликованы в коде сайта, поэтому их стоит заменить.

1. **В скрипте** (`DEFAULT_CODES`) впишите новые коды и обновите развёртывание.
2. **На сайте** обновите хеши, чтобы вход работал и без сервера:
   откройте главную страницу, нажмите F12 → Console и выполните
   ```js
   await sha256Hex('smb-portal:' + normalizeCode('НОВЫЙ_КОД'))
   ```
   Полученную строку вставьте в `codeHashes` нужного курса в `index.html`
   и как ключ в `DEFAULT_COURSE_CODES` в `geotanu/geotanu.html`.

Дополнительные коды (для отдельных групп) можно создавать прямо в
админ-панели, вкладка «Курс кодтары» — они хранятся в листе «Коды».

## 🚀 Навигация

* `/index.html` — вход. Параметр `?redirect=` принимает только страницы этого
  сайта (например `geotanu/topics/topic_5.html`); внешние адреса и `javascript:`
  отбрасываются.
* `/geotanu/index.html`, `/geonish/index.html` — без входа отправляют на главную.
* `/geotanu/nomenklatura/` — открывает казахскую или русскую версию игры
  по выбранному языку.
