# Путь Шошо — промпты, ВСТУПЛЕНИЕ «Иллюзия внимания» (версия 2)

Статус: p1 и p2 выбраны (первые генерации). Остальные кадры генерировать заново по этим промптам.
Порядок в чате генератора: 1) блок СТИЛЬ+ПЕРСОНАЖ, 2) блок ФОРМА, 3) промпт кадра. Для p3–p9 прикладывать p2 как референс детского Шошо.

Технические требования ко ВСЕМ кадрам
- Вертикаль 4:5, минимум 1080×1350 px (лучше 1600×2000). Не квадрат.
- Без текста: ни букв, ни иероглифов, ни цифр, ни звуковых надписей (SFX), ни вывесок, ни флагов, ни логотипов.
- Главный объект в центральных 60% кадра; по краям по 5% запас (движок трясёт и двигает кадр).
- Зона под надпись: ровная, спокойная, без деталей и контрастных линий (на неё ляжет белый/светлый текст).
- Файлы называть p3.jpg, p3b.jpg … (JPG, до 400 КБ после сжатия).
